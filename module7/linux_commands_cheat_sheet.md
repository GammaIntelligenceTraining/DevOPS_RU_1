# Модуль 7: Продвинутая автоматизация на Bash — Шпаргалка

Справочная таблица по продвинутым конструкциям ветвления, модульным функциям, типам данных, массивам, потоковым циклам и защитным механизмам Bash.

---

## 1. Конструкции ветвления и логические операторы

| Синтаксис | Назначение | Пример использования |
| :--- | :--- | :--- |
| `if ... elif ... else` | Каскадное ветвление условий | `if [[ $A -eq 1 ]]; then ... elif [[ $A -eq 2 ]]; then ... fi` |
| `[[ $X && $Y ]]` | Логическое И (оба условия истинны) | `if [[ -f "$FILE" && -r "$FILE" ]]; then` |
| `[[ $X \|\| $Y ]]` | Логическое ИЛИ (хотя бы одно истинно) | `if [[ -z "$A" \|\| -z "$B" ]]; then` |
| `[[ ! $X ]]` | Логическое НЕ (инверсия условия) | `if [[ ! -d "$DIR" ]]; then` |
| `if command; then` | Проверка успешного завершения команды (код 0) | `if ping -c 1 "$IP" >/dev/null 2>&1; then` |
| `${VAR:-default}` | Значение по умолчанию, если переменная не задана | `PORT="${1:-8080}"` |

## 2. Модульные функции и область видимости

| Конструкция | Назначение | Пример использования |
| :--- | :--- | :--- |
| `name() { ... }` | Объявление функции | `log_msg() { echo "[INFO] $1"; }` |
| `local VAR="val"` | Локальная переменная (видима только внутри функции) | `local count=0` |
| `return N` | Возврат числового кода статуса (0–255) | `return 1` |
| `$1`, `$2`, `$#` | Аргументы функции и их общее количество | `echo "Первый аргумент: $1, всего: $#"` |
| `RES="$(func)"` | Захват текстового вывода функции через subshell | `CURRENT_IP="$(get_server_ip)"` |

## 3. Целочисленная арифметика и команда `declare`

| Конструкция | Назначение | Пример использования |
| :--- | :--- | :--- |
| `$(( expression ))` | Вычисление целочисленного выражения | `RESULT=$(( (TOTAL * 100) / LIMIT ))` |
| `$(( A % B ))` | Вычисление остатка от деления (модуль) | `REMAINDER=$(( TOTAL % BATCH_SIZE ))` |
| `declare -i` | Целочисленная переменная | `declare -i WORKERS=4; WORKERS+=2` |
| `declare -r` | Константа (только для чтения) | `declare -r BASE_DIR="/opt/app"` |
| `declare -l` | Автоматическое приведение к нижнему регистру | `declare -l ENV_NAME="PROD"` |
| `declare -u` | Автоматическое приведение к верхнему регистру | `declare -u ROLE="admin"` |
| `declare -p VAR` | Вывод внутреннего определения и атрибутов переменной | `declare -p WORKERS` |

## 4. Индексированные массивы (Списки)

| Синтаксис | Назначение | Пример использования |
| :--- | :--- | :--- |
| `declare -a ARR=("A" "B")` | Объявление и инициализация списка | `declare -a HOSTS=("srv1" "srv2")` |
| `ARR+=("val")` | Добавление нового элемента в конец | `HOSTS+=("srv3")` |
| `${ARR[0]}` | Получение элемента по нулевому индексу | `FIRST="${HOSTS[0]}"` |
| `"${ARR[@]}"` | Обращение ко всем элементам с защитой от пробелов | `for H in "${HOSTS[@]}"; do ... done` |
| `${#ARR[@]}` | Общее количество элементов в массиве | `echo "Всего хостов: ${#HOSTS[@]}"` |

## 5. Ассоциативные массивы (Словари)

| Синтаксис | Назначение | Пример использования |
| :--- | :--- | :--- |
| `declare -A MAP` | Обязательное объявление ассоциативного массива (хеш-таблицы) | `declare -A PORTS` |
| `declare -A M=(["k"]="v")` | Компактное литеральное объявление и инициализация словаря | `declare -A SRV=(["auth"]="10.0.1.15:8080")` |
| `MAP["key"]="val"` | Назначение значения по строковому ключу | `PORTS["http"]=80` |
| `${MAP["key"]}` | Получение значения по ключу | `echo "Порт HTTP: ${PORTS["http"]}"` |
| `"${!MAP[@]}"` | Извлечение всех зарегистрированных ключей | `for KEY in "${!PORTS[@]}"; do ... done` |
| `"${MAP[@]}"` | Извлечение всех значений словаря | `echo "Все порты: ${PORTS[@]}"` |
| `unset MAP["key"]` | Удаление пары ключ-значение | `unset PORTS["http"]` |

## 6. Потоковые циклы и защита скриптов

| Синтаксис | Назначение | Пример использования |
| :--- | :--- | :--- |
| `while read -r L; do ... done < file` | Безопасное построчное чтение файла | `while read -r LINE; do ... done < hosts.txt` |
| `done < <(command)` | Подстановка процесса для исключения Subshell Trap | `while read -r L; do ... done < <(cat logs.txt)` |
| `for (( i=1; i<=N; i++ ))` | Счетный цикл в стиле Си | `for (( i=1; i<=5; i++ )); do ... done` |
| `cmd \|\| true` | Подавление прерывания по set -e для некритичной команды | `rm -f /tmp/test.tmp \|\| true` |
| `${PIPESTATUS[@]}` | Массив кодов возврата всех команд последнего конвейера | `echo "Статусы пайпа: ${PIPESTATUS[*]}"` |

## 7. Нативная трансформация параметров (Parameter Expansions)

| Синтаксис | Назначение | Пример использования |
| :--- | :--- | :--- |
| `${VAR:-default}` | Значение по умолчанию (если переменная не задана или пуста) | `PORT="${PORT:-8080}"` |
| `${VAR:?error_msg}` | Завершение скрипта с ошибкой, если переменная не задана | `FILE="${1:?Не указан путь к файлу}"` |
| `${VAR##*/}` | Жадное удаление префикса до последнего слэша (аналог `basename`) | `FILENAME="${FILEPATH##*/}"` |
| `${VAR%/*}` | Удаление последнего слэша и имени файла (аналог `dirname`) | `DIR="${FILEPATH%/*}"` |
| `${VAR%.*}` | Удаление последнего суффикса расширения с конца строки | `BASE="${ARCHIVE%.gz}"` |
| `${VAR%%.*}` | Жадное удаление всех составных расширений с конца строки | `NAME="${ARCHIVE%%.*}"` |
| `${VAR//pattern/replace}` | Замена всех вхождений подстроки без запуска внешнего sed | `CLEAN="${NAME//-/_}"` |
| `${VAR:offset:len}` | Извлечение среза подстроки по смещению и длине | `DATE="${FILENAME:0:10}"` |
