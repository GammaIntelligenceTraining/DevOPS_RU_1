# Домашнее задание к Модулю 2: Безопасность и управление доступом

Практическая работа по базовому системному администрированию Linux: управление учетными записями и группами, разграничение прав доступа (DAC), безопасное делегирование привилегий в sudoers и контроль фоновых процессов.

---

## Задание 1: Создание пользователя и группы

**Цель:** Создать рабочую учетную запись аналитика данных `analyst_bob` и настроить его членство в группе.

**Требования:**
1. Создайте системную группу `analytics`.
2. Создайте пользователя `analyst_bob` с персональным домашним каталогом (`-m`) и оболочкой `/bin/bash` (`-s`).
3. Задайте пароль для созданной учетной записи.
4. Добавьте пользователя `analyst_bob` в дополнительную группу `analytics` (обязательно используйте флаг `-a`).

**Самопроверка:**
Проверьте идентификаторы созданного пользователя и состав его групп:
```bash
id analyst_bob
# Ожидается: uid=...(analyst_bob) gid=...(analyst_bob) groups=...(analyst_bob),...(analytics)
```

## Задание 2: Настройка командного каталога и прав доступа (DAC)

**Цель:** Подготовить изолированный каталог `/srv/analytics` для совместной работы аналитиков с полным запретом доступа посторонним.

**Требования:**
1. Создайте каталог `/srv/analytics` и файл данных `/srv/analytics/data.csv`.
2. Рекурсивно назначьте владельцем каталога пользователя `analyst_bob` и группу `analytics` (`chown -R`).
3. Установите права `770` на каталог `/srv/analytics` (владельцу и группе полный доступ, остальным доступ полностью закрыт).
4. Установите права `640` на файл `/srv/analytics/data.csv` (владельцу чтение/запись, группе чтение, остальным доступ закрыт).

**Самопроверка:**
Проверьте метаданные каталога и файла данных:
```bash
ls -ld /srv/analytics
# Ожидается: drwxrwx--- ... analyst_bob analytics ... /srv/analytics

ls -l /srv/analytics/data.csv
# Ожидается: -rw-r----- ... analyst_bob analytics ... /srv/analytics/data.csv
```

## Задание 3: Делегирование прав через Sudoers

**Цель:** Разрешить участникам группы `analytics` выполнять обновление кэша пакетов от имени суперпользователя без запроса пароля.

**Требования:**
1. Создайте файл модульных правил `/etc/sudoers.d/analytics_team` с помощью безопасной утилиты `visudo -f`.
2. Добавьте правило, разрешающее группе `%analytics` выполнение команды `/usr/bin/apt update` без пароля (`NOPASSWD:`).
3. Проверьте синтаксическую корректность созданного правила командой `sudo visudo -cf /etc/sudoers.d/analytics_team`.

**Самопроверка:**
Проверьте список действующих разрешений sudo для аналитика:
```bash
sudo -l -U analyst_bob
# Ожидается: (%analytics) NOPASSWD: /usr/bin/apt update
```

## Задание 4: Управление фоновыми задачами (Job Control)

**Цель:** Отработать запуск длительной команды в фоновом режиме, контроль состояния задач и отправку сигналов завершения.

**Требования:**
1. Запустите команду `sleep 300` в фоновом режиме текущей сессии с помощью символа `&`.
2. Проверьте статус запущенной задачи в списке фоновых процессов оболочки (`jobs`).
3. Завершите фоновый процесс штатным сигналом остановки (`kill %1`).
4. Убедитесь, что задача удалена из списка активных процессов.

**Самопроверка:**
Проверьте список фоновых задач после отправки сигнала остановки:
```bash
jobs
# Ожидается: пустой вывод (все фоновые задачи завершены)
```

## Очистка учебного стенда (Teardown)

После завершения и проверки всех заданий выполните очистку созданных учебных объектов:

Команда идемпотентного удаления тестового пользователя, группы, каталога и файла правил sudoers:
```bash
sudo userdel -r analyst_bob 2>/dev/null || true
sudo groupdel analytics 2>/dev/null || true
sudo rm -rf /srv/analytics /etc/sudoers.d/analytics_team
```
