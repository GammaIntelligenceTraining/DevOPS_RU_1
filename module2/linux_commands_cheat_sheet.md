# Шпаргалка по основным командам Linux к Модулю 2

Справочная таблица команд, рассмотренных в **Модуле 2: Безопасность и управление доступом**, с описанием их практического применения в enterprise-инфраструктуре и production-средах.

---

## 1. Проверка идентификаторов и учетных записей

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `whoami` | Отображает имя текущего активного пользователя | Аудит контекста безопасности в раннерах CI/CD: определение пользователя, выполняющего шаги пайплайна (`whoami`) |
| `id` | Показывает текущий UID, основной GID и список дополнительных групп | Диагностика привилегий: проверка UID/GID и групп перед запуском чувствительных операций (`id`) |
| `id [user]` | Проверяет UID и группы конкретного пользователя | Аудит онбординга: проверка состава групп выделенной сервисной учетной записи (`id deploy_bot`) |
| `groups` | Выводит список групп текущего пользователя | Аудит прав: проверка наличия доступа к группам `docker` или `sudo` у текущего инженера (`groups`) |
| `groups [user]` | Отображает группы указанного пользователя | Аудит доступа: подтверждение членства разработчика в группе проектного репозитория (`groups dev_student`) |

## 2. Управление пользователями и группами

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `sudo useradd -m -s [shell] [user]` | Создает нового пользователя с домашним каталогом и оболочкой | Автоматизация подготовки сред: создание сервисного аккаунта запуска приложения (`sudo useradd -m -s /bin/bash app_runner`) |
| `sudo passwd [user]` | Устанавливает или изменяет пароль пользователя | Ротация учетных данных: назначение первичного временного пароля новому сотруднику (`sudo passwd analyst_bob`) |
| `sudo passwd -l [user]` | Блокирует пароль аккаунта (отключает аутентификацию по паролю) | Изоляция инцидентов: немедленная блокировка скомпрометированной учетной записи (`sudo passwd -l compromised_user`) |
| `sudo passwd -u [user]` | Снимает блокировку с пароля учетной записи | Восстановление доступа: разблокировка аккаунта после сброса учетных данных и настройки MFA (`sudo passwd -u restored_user`) |
| `sudo passwd -S [user]` | Показывает статус пароля (P=активен, L=заблокирован, NP=нет пароля) | Аудит соответствия: проверка статусов паролей учетных записей при проверках SOC 2 и ISO (`sudo passwd -S deploy_bot`) |
| `sudo usermod -aG [group] [user]` | Добавляет пользователя в дополнительную группу (всегда указывайте `-a`) | Делегирование доступа: добавление инженера в группу `docker` без удаления из других групп (`sudo usermod -aG docker dev_student`) |
| `sudo userdel -r [user]` | Удаляет учетную запись пользователя и его домашний каталог | Оффбординг: корректная зачистка аккаунта уволенного подрядчика и удаление его каталогов (`sudo userdel -r contractor_tom`) |
| `sudo groupadd [group]` | Создает новую системную группу | Разграничение доступа: создание общекомандной группы для совместной работы над проектом (`sudo groupadd data_platform`) |
| `sudo gpasswd -d [user] [group]` | Исключает пользователя из указанной группы | Отзыв прав: удаление разработчика из привилегированной группы без удаления аккаунта (`sudo gpasswd -d dev_student analytics`) |
| `sudo groupdel [group]` | Удаляет группу из операционной системы | Очистка системы: удаление устаревшей проектной группы после завершения миграции (`sudo groupdel legacy_team`) |

## 3. Переключение пользовательского окружения

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `su [user]` | Переключается на пользователя с сохранением текущего окружения | Тестирование окружения: переключение с сохранением переменных шелла и текущего каталога (`su dev_student`) |
| `su - [user]` | Переключается на пользователя с чистым окружением логина | Точная симуляция: запуск сессии с чистым окружением и переменной PATH целевого пользователя (`su - dev_student`) |
| `sudo su - [user]` | Переключается на любого пользователя с правами суперпользователя | Администрирование SRE: безопасный вход под системной учетной записью без знания ее пароля (`sudo su - www-data`) |
| `exit` | Завершает текущую сессию командного интерпретатора | Управление сессиями: выход из вложенного шелла и возврат к родительскому сеансу (`exit`) |

## 4. Права доступа к файлам и каталогам (`chmod`)

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `chmod u+x [file]` | Предоставляет право на выполнение владельцу файла | Подготовка скриптов: выдача прав на запуск только автору скрипта (`chmod u+x backup.sh`) |
| `chmod g+w [file]` | Разрешает запись участникам группы файла | Совместная работа: предоставление прав на редактирование манифеста участникам команды (`chmod g+w k8s-deploy.yaml`) |
| `chmod o-rwx [file]` | Отзывает все права у категории «остальные» | Защита данных: закрытие доступа непривилегированным пользователям к токенам (`chmod o-rwx api_token.env`) |
| `chmod a+r [file]` | Предоставляет право на чтение всем (владельцу, группе, остальным) | Публикация файлов: обеспечение глобального чтения публичной документации или конфигов (`chmod a+r release_notes.txt`) |
| `chmod 755 [file/dir]` | Устанавливает rwxr-xr-x (стандарт для скриптов и каталогов) | Выпуск релизов: типовой режим для бинарников, шелл-скриптов и открытых веб-каталогов (`chmod 755 /srv/app/start.sh`) |
| `chmod 644 [file]` | Устанавливает rw-r--r-- (стандарт для конфигов и файлов данных) | Базовая безопасность: чтение/запись владельцу, только чтение сервисам и остальным (`chmod 644 /etc/nginx/nginx.conf`) |
| `chmod 600 [file]` | Устанавливает rw------- (чтение/запись только владельцу) | Защита секретов: строгие права только для владельца, стандарт для токенов и паролей БД (`chmod 600 /opt/secrets/db.env`) |
| `chmod 700 [dir]` | Устанавливает rwx------ (полный доступ только владельцу) | Защита профиля: ограничение доступа к закрытым каталогам (`chmod 700 /opt/secure_vault`) |
| `chmod 770 [dir]` | Устанавливает rwxrwx--- (полный доступ владельцу и группе) | Изоляция команд: владелец и группа имеют полный доступ, остальные заблокированы (`chmod 770 /opt/analytics_data`) |
| `chmod 775 [dir]` | Устанавливает rwxrwxr-x (стандарт для общих рабочих каталогов) | Совместное пространство: полный доступ владельцу и группе, остальным чтение и вход (`chmod 775 /var/shared_projects`) |
| `chmod -R [mode] [dir]` | Рекурсивно применяет права ко всему дереву каталогов | Массовое развертывание: применение политики наименьших привилегий ко всей структуре сервиса (`chmod -R 750 /srv/web_service`) |
| `find [dir] -perm 777` | Находит небезопасные файлы и каталоги с правами 777 | Сканирование уязвимостей: обнаружение опасных объектов с полным доступом на запись для всех (`find /var/www -perm 777`) |
| `find [dir] -user [name]` | Находит файлы и каталоги, принадлежащие указанному пользователю | Инвентаризация доступа: поиск всех файлов сотрудника перед удалением аккаунта (`find /opt -user dev_student`) |
| `find [dir] -group [name]` | Находит файлы и каталоги, закрепленные за указанной группой | Аудит проектов: проверка объектов совместного доступа рабочей группы (`find /srv -group engineering`) |
| `find [dir] -type d / -type f` | Разделяет поиск только по директориям или только по регулярным файлам | Безопасная настройка прав: раздельное изменение прав на каталоги и файлы (`find /opt -type d`) |
| `find [dir] -nouser` | Находит файлы, владельцы которых удалены из операционной системы | Аудит безопасности: поиск «осиротевших» файлов после удаления учетных записей (`find /tmp -nouser`) |

## 5. Управление владением (`chown`, `chgrp`)

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `sudo chown [user] [file]` | Назначает нового владельца файла | Назначение владельца: передача конфигурации сервисному пользователю демона (`sudo chown www-data /etc/app.conf`) |
| `sudo chown [user]:[group] [file]` | Одновременно изменяет владельца и группу файла | Полное делегирование: настройка владельца и группы одной командой (`sudo chown deploy_bot:devops /opt/app/deploy.sh`) |
| `sudo chgrp [group] [file]` | Изменяет группу-владельца файла | Назначение проекта: обновление группы файла под проектную команду (`sudo chgrp analytics /srv/reports/q1.csv`) |
| `sudo chown -R [user]:[group] [dir]` | Рекурсивно меняет владельца и группу для всего дерева каталогов | Подготовка инфраструктуры: передача структуры каталогов приложения сервисному аккаунту (`sudo chown -R www-data:www-data /var/www/html`) |

## 6. Повышение привилегий и делегирование Sudo

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `sudo [command]` | Выполняет команду с правами суперпользователя | Привилегированный запуск: выполнение отдельной административной команды под аудитом (`sudo systemctl restart nginx`) |
| `sudo -l` | Отображает список разрешенных команд sudo для пользователя | Проверка привилегий: аудит действующих правил sudoers для себя или целевого аккаунта (`sudo -l` или `sudo -l -U deploy_bot`) |
| `sudo visudo` | Безопасно редактирует `/etc/sudoers` с блокировкой и проверкой | Безопасная настройка: редактирование файла sudoers с контролем синтаксиса перед записью (`sudo visudo`) |
| `sudo visudo -cf [file]` | Проверяет синтаксис файла правил в `/etc/sudoers.d/` | Предотвращение ошибок: валидация модульного файла drop-in перед его активацией (`sudo visudo -cf /etc/sudoers.d/analytics_team`) |

## 7. Аудит безопасности и анализ сессий

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `who` | Отображает список пользователей, подключенных к серверу | Аудит сессий: просмотр активных подключений, псевдотерминалов и пользователей (`who`) |
| `w` | Показывает активных пользователей, нагрузку и выполняемые команды | Оперативный анализ: контроль загрузки процессора, времени простоя и команд в активных сессиях (`w`) |
| `loginctl list-sessions` | Выводит список всех активных пользовательских сессий | Аудит сессий systemd: отслеживание активных подключений пользователей, терминалов и идентификаторов сеансов (`loginctl list-sessions`) |
| `loginctl list-users` | Отображает список пользователей с активными сеансами | Инспекция пользователей: определение учетных записей, авторизованных в операционной системе в текущий момент (`loginctl list-users`) |
| `loginctl session-status [id]` | Показывает подробную информацию о конкретной сессии | Расследование инцидентов: инспекция дерева процессов, cgroup и активности конкретной пользовательской сессии (`loginctl session-status 2`) |

## 8. Управление фоновыми задачами и процессами

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `[command] &` | Запускает команду в фоновом режиме | Запуск длительных скриптов обслуживания или миграций данных без блокировки сессии терминала. |
| `jobs` | Выводит список активных фоновых задач текущей оболочки | Отслеживание фоновых задач, запущенных в текущей сессии оболочки, перед завершением сеанса. |
| `bg %[job_id]` | Возобновляет приостановленную задачу в фоне | Перевод в фоновый режим тяжелой операции сжатия или передачи файлов, ошибочно запущенной на переднем плане. |
| `fg %[job_id]` | Возвращает фоновую задачу на передний план | Возврат к процессу переднего плана для контроля интерактивного прогресса или передачи стандартного ввода. |
| `kill [PID]` | Отправляет сигнал SIGTERM (15) для штатной остановки | Корректное завершение веб-серверов или баз данных с закрытием сетевых сокетов и дескрипторов файлов. |
| `kill -9 [PID]` | Отправляет сигнал SIGKILL (9) для немедленного уничтожения | Безусловное принудительное завершение зависших или заблокированных процессов, не отвечающих на сигнал SIGTERM. |
| `pkill [name]` | Завершает процессы, соответствующие имени | Остановка всех процессов-воркеров, связанных с конкретным демоном, по всей системе. |

## 9. Доступ к накопителю хоста

| Команда | Платформа | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- | :--- |
| `ls /mnt/c` | Windows (WSL 2) | Просматривает диск C: хоста Windows | Доступ к локальным репозиториям кода, конфигурациям или скриптам хоста из гостевой системы Linux. |
| `multipass mount [host_path] [vm]:[target_path]` | macOS (Multipass) | Монтирует каталог хоста в виртуальную машину | Быстрая передача файлов конфигураций и артефактов между хостом macOS и облачным инстансом Ubuntu. |
