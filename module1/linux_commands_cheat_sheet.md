# Шпаргалка по основным командам Linux к Модулю 1

Справочная таблица команд, рассмотренных в **Модуле 1: Основы, инструментарий и процессы**, с подробным описанием их практического применения в корпоративной DevOps-инженерии и production-средах.

---

## 1. Жизненный цикл виртуальных машин (WSL 2 и Multipass)

| Команда | Платформа | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- | :--- |
| `wsl --install -d Ubuntu --name [vm]` | Windows PS | Создает и устанавливает именованный инстанс Ubuntu | Быстрый запуск изолированной, воспроизводимой локальной песочницы Ubuntu, зеркалирующей серверные production-среды. |
| `wsl -l -v` | Windows PS | Выводит список всех установленных инстансов WSL и их статус | Аудит версий локального окружения разработчика и подтверждение того, что инстансы работают на WSL версии 2. |
| `wsl -d [vm]` | Windows PS | Запускает инстанс и подключает интерактивную оболочку | Прямое подключение к конкретной песочнице разработки, соответствующей целевому production-дистрибутиву. |
| `exit` / `Ctrl+D` | Linux Shell | Отключается от оболочки Linux и возвращает в терминал хоста | Безопасное отключение от интерактивной сессии сервера без остановки фоновых демонов. |
| `wsl -t [vm]` | Windows PS | Останавливает / завершает конкретный работающий инстанс | Высвобождение оперативной памяти и ресурсов процессора хоста путем отключения простаивающих виртуальных машин. |
| `wsl --shutdown` | Windows PS | Принудительно останавливает все работающие инстансы WSL | Жесткий перезапуск подсистемы виртуализации после редактирования `/etc/wsl.conf` для включения systemd. |
| `multipass launch --name [vm]` | macOS | Создает и запускает облачный инстанс Ubuntu | Развертывание виртуальной машины Ubuntu с поддержкой cloud-init, имитирующей инстанс AWS EC2 на рабочей станции macOS / Apple Silicon. |
| `multipass list` | macOS | Выводит список всех ВМ Multipass, их статусы и IPv4-адреса | Определение назначенных динамических IP-адресов локальных тестовых узлов микросервисов. |
| `multipass info [vm]` | macOS | Отображает детальные характеристики ресурсов и статистику ВМ | Проверка утилизации CPU, оперативной памяти и диска локальных тестовых узлов перед запуском нагрузочного тестирования. |
| `multipass start [vm]` | macOS | Запускает остановленную виртуальную машину в фоне | Возобновление тестирования кластерных симуляций без необходимости переустановки базовых пакетов. |
| `multipass shell [vm]` | macOS | Подключает интерактивную оболочку к виртуальной машине | Доступ к командной строке headless-узла Ubuntu для настройки и отладки. |
| `multipass stop [vm]` | macOS | Корректно останавливает работающую виртуальную машину | Сброс буферов файловой системы на диск и штатное завершение сервисов перед переходом хоста в спящий режим. |
| `multipass delete [vm] && multipass purge` | macOS | Безвозвратно удаляет виртуальную машину и освобождает диск | Уничтожение временных тестовых сред после выполнения автоматизированных интеграционных тестов инфраструктуры. |

## 2. Информация о системе и окружении

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `whoami` | Отображает имя текущего вошедшего пользователя | Проверка контекста безопасности в раннерах CI/CD-пайплайнов (например, проверка прав `gitlab-runner` против `root`). |
| `uname -a` | Выводит всю информацию о системе и ядре | Проверка версии ядра и архитектуры (`x86_64` против `aarch64`) перед компиляцией бинарных файлов или загрузкой модулей eBPF. |
| `hostname` | Отображает сетевое имя хоста системы | Идентификация узла в топологии кластера (например, различие между `web-prod-01` и `web-prod-02`). |
| `hostname -I` | Показывает назначенные внутренние IP-адреса | Получение частного IPv4-адреса для динамической регистрации бэкенда в Consul или механизмах service discovery. |
| `ps -p 1 -o comm=` | Проверяет имя процесса с PID 1 | Проверка того, что `systemd` является активной системой инициализации перед запуском сервисов или фоновых демонов. |

## 3. Навигация и иерархия директорий

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `pwd` | Выводит текущий рабочий каталог (Print Working Directory) | Подтверждение точного расположения в файловой системе перед выполнением деструктивных пакетных операций или очистки. |
| `cd [dir]` | Сменяет текущий каталог (Change Directory) | Переход к конфигурациям сервисов (`/etc/nginx`), корневым каталогам веб-документов (`/var/www`) или рабочим пространствам пользователей. |
| `cd -` | Возвращает в предыдущий рабочий каталог | Быстрое переключение между глубокими путями развертывания и каталогами анализа логов. |
| `ls` | Выводит список видимых файлов и директорий | Быстрый просмотр содержимого каталога без загрузки подробных метаданных. |
| `ls -l` | Детальный длинный вывод (права, владелец, размер) | Аудит прав доступа к файлам, групп владельцев и точных размеров конфигурационных файлов и бинарников. |
| `ls -la` | Выводит все файлы, включая скрытые dot-файлы (`.`) | Обнаружение скрытых файлов переменных окружения (`.env`), токенов деплоя и метаданных репозитория git (`.git`). |
| `ls -lh` | Отображает размеры файлов в удобном формате (K, M, G) | Оценка размеров лог-файлов или дампов баз данных для предотвращения переполнения дискового пространства корневого раздела. |
| `ls -lt` | Сортирует файлы по времени изменения (сначала новые) | Идентификация недавно созданных артефактов сборки или определение файлов, измененных во время инцидента. |
| `ls -lart` | Обратная сортировка по времени: свежие изменения внизу | Быстрое реагирование на инциденты: отображение самых последних измененных логов или дампов ошибок внизу экрана терминала. |
| `ls -ld [dir]` | Отображает метаданные самого каталога, а не его файлов | Проверка прав доступа и владельца самого каталога без вывода тысяч вложенных файлов. |
| `ls -R [dir]` | Рекурсивно выводит все подкаталоги и файлы | Картирование структуры кодовой базы приложения или проверка вложенных деревьев шаблонов. |

## 4. Операции с файлами и редактирование текста

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `mkdir -p [path]` | Идемпотентно создает каталог и все родительские папки | Гарантированное создание структуры каталогов для деплоя в скриптах CI/CD без падения по ошибке, если директория уже есть. |
| `touch [file]` | Создает пустой файл или обновляет временную метку | Создание lock-файлов триггеров (например, `/tmp/maintenance.flag`) или обновление временных меток для перезагрузки контейнеров. |
| `cp [src] [dst]` | Копирует отдельный файл | Создание мгновенных локальных резервных копий перед изменением критических конфигураций (например, `nginx.conf.bak`). |
| `cp -i [src] [dst]` | Копирует файл с запросом подтверждения перезаписи | Предотвращение случайной перезаписи критических файлов конфигурации при ручных работах. |
| `cp -r [src] [dst]` | Рекурсивно копирует всю директорию целиком | Репликация статических веб-ассетов, репозиториев приложений или каталогов конфигураций. |
| `cp -a [src] [dst]` | Архивное копирование: сохраняет права, владельца и даты | Безопасное резервное копирование системных файлов без потери прав доступа, атрибутов владения и временных меток. |
| `mv [src] [dst]` | Перемещает или переименовывает файл или каталог | Атомарная подмена конфигурационных файлов или перемещение артефактов сборки в рабочий каталог продакшена. |
| `mv -i [src] [dst]` | Перемещает или переименовывает с запросом подтверждения | Защита от непреднамеренной перезаписи целевых файлов при миграциях и ротации конфигов. |
| `rm [file]` | Безвозвратно удаляет файл (корзины нет!) | Удаление ротированных архивов логов или устаревших временных файлов для освобождения диска. |
| `rm -i [file]` | Запрашивает подтверждение перед удалением каждого файла | Защитная мера при ручной очистке рабочих директорий на критических серверах. |
| `rm -r [dir]` | Рекурсивно удаляет каталог | Удаление устаревших каталогов релизов или неактуальных версий приложений. |
| `rm -rf [dir]` | Принудительно и рекурсивно удаляет каталог без запросов | Очистка артефактов сборки и кэшей компиляции в автоматизированных раннерах CI/CD без интерактивных подтверждений. |
| `echo "[text]"` | Выводит текстовую строку на экран терминала | Вывод диагностических сообщений или значений переменных в шелл-скриптах и сессиях терминала. |
| `echo "[text]" > [file]` | Записывает/перезаписывает текст в файл | Перезапись флагов конфигурации сервисов или генерация начальных переменных окружения при инициализации контейнера. |
| `echo "[text]" >> [file]` | Добавляет текст в конец файла без перезаписи | Безопасное добавление правил фаервола, переменных окружения или записей хостов (`/etc/hosts`). |
| `nano [file]` | Открывает терминальный текстовый редактор (`Ctrl+O` сохранить, `Ctrl+X` выйти) | Оперативное внесение hotfix-правок на удаленных облачных серверах по SSH в отсутствие графического интерфейса. |

## 5. Просмотр текста и поиск

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `cat [file]` | Выводит все содержимое файла на экран | Просмотр небольших конфигурационных файлов, метаданных релизов или передача файлов по конвейеру в сетевые утилиты. |
| `less [file]` | Интерактивный пейджер для навигации по большим файлам | Постраничный просмотр многогигабайтных production-логов без исчерпания оперативной памяти, с поиском через `/шаблон`. |
| `head -n [N] [file]` | Отображает первые $N$ строк файла | Просмотр заголовков файлов, структуры CSV-таблиц или проверка строк shebang в загруженных скриптах. |
| `tail -n [N] [file]` | Отображает последние $N$ строк файла | Быстрая проверка последних сообщений об ошибках или кодов завершения, записанных в конце лога. |
| `tail -f [file]` | Отслеживает и выводит новые записи в файл в реальном времени | Непрерывный мониторинг в продакшене: отслеживание входящих HTTP-запросов или исключений приложения во время развертывания. |
| `grep [pattern] [file]` | Ищет строки, соответствующие шаблону | Поиск в логах приложения конкретных кодов ошибок HTTP (например, `grep "500 Internal" /var/log/nginx/access.log`). |
| `grep -i [pattern] [file]` | Регистронезависимый поиск по шаблону | Поиск в логах маркеров сбоев независимо от регистра написания (например, `error`, `ERROR`, `Error`). |
| `grep -rn [pattern] [dir]` | Рекурсивный поиск по каталогу с номерами строк | Сканирование кодовых баз микросервисов для выявления жестко заданных паролей, строк подключения к БД или устаревших параметров. |
| `grep -v [pattern] [file]` | Инвертированный поиск: строки, НЕ содержащие шаблон | Фильтрация комментариев и пустых строк из конфигурационных файлов для отображения только активных директив (`grep -v '^#'`). |
| `command \| grep [pat]` | Перенаправляет вывод команды через фильтр grep | Фильтрация системных таблиц в реальном времени (например, `ps aux \| grep nginx` или `ss -tulpn \| grep 8080`). |

## 6. Управление пакетами (`apt`)

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `sudo apt update` | Обновляет локальный каталог доступных пакетов | Синхронизация локальных метаданных пакетов с апстрим-зеркалами репозиториев перед установкой ПО или обновлений. |
| `apt search [keyword]` | Ищет программное обеспечение в репозитории пакетов | Определение точного имени пакета для системных библиотек или серверных демонов перед добавлением в скрипты провижининга. |
| `apt show [pkg]` | Отображает версию пакета, зависимости и описание | Проверка версий пакетов, сведений о мейнтейнере и предварительных зависимостей для аудита безопасности. |
| `sudo apt install -y [pkg]` | Устанавливает пакет без интерактивных запросов | Автоматизация установки утилит в Dockerfile, скриптах провижининга CI/CD и плейбуках настройки серверов. |
| `apt list --installed` | Выводит список установленных пакетов (фильтруется через grep) | Формирование инвентарного списка установленного программного обеспечения на сервере для аудитов соответствия. |
| `sudo apt remove [pkg]` | Удаляет пакет, но сохраняет файлы конфигурации | Удаление бинарного файла приложения с сохранением кастомных конфигураций для возможной повторной установки. |
| `sudo apt purge [pkg]` | Удаляет пакет И полностью стирает все его конфигурации | Полное удаление устаревшего или скомпрометированного ПО вместе со всеми конфигурациями для исключения дрейфа настроек. |
| `sudo apt autoremove -y` | Удаляет неиспользуемые изолированные зависимости | Очистка старых версий ядер Linux и брошенных библиотек для освобождения места на корневом разделе. |
| `sudo apt clean` | Очищает локальный кэш загруженных архивов пакетов | Удаление скачанных `.deb`-пакетов из `/var/cache/apt/archives` для экономии места на компактных облачных инстансах. |
| `sudo apt upgrade -y` | Обновляет все установленные пакеты до актуальных версий | Применение критических патчей безопасности и обновлений ядра по всему парку staging- и production-серверов. |

## 7. Мониторинг процессов

| Команда | Описание | Применение в Enterprise и Production |
| :--- | :--- | :--- |
| `ps aux` | Полный снимок всех активных процессов в системе | Аудит владельцев процессов, утилизации CPU/RAM и аргументов командной строки для выявления зависших задач. |
| `top` | Интерактивный диспетчер задач реального времени (`Shift+M` сорт. по RAM, `Shift+P` по CPU) | Быстрый интерактивный анализ перегруженного сервера для выявления процесса, утилизирующего ядра процессора. |
| `htop` | Современный визуальный монитор процессов (`F5` режим дерева, `q` выход) | Глубокий анализ инцидентов: визуализация нагрузки по ядрам CPU, иерархии потоков и связей процессов "родитель-потомок". |
